## 如何切换分支

完整产品资料在各**版本分支**中；`main` 仅作导航。

- **网页：** 在仓库页左上角打开分支下拉框，选择与料号对应的版本分支即可。
- **命令行：** 克隆本仓库后执行 `git checkout <版本分支名>`；若本地已有仓库，先 `git fetch` 再切换。
